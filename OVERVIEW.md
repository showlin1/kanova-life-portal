# Kanova Life – Course Booking

Public website for Kanova Life (Canadian Red Cross Training Partner, Thunder Bay). Visitors browse first aid / CPR courses and book a session: choose a main city, then a training location in that city, pick an available date (with seats left) on one calendar, add participant details, apply a promo code, and check out.

An admin dashboard at /admin (sign-in + approved admin emails only) lets the owner manage courses, session schedules and capacity, cities and sub-cities, promo codes, participants, bookings/payments and emails.

Current stage: interactive prototype. The booking flow and dashboard run on sample data stored in the browser; payments and emails are simulated. The plan is to connect a real backend (Wix Headless: Bookings, checkout/payments, coupons, CMS, plus an email provider) later.
